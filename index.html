◈ SentinelApplication security scanning for modern teams · 100% client-side
Scope: Sentinel performs URL-structure analysis only (no live page fetch, due to browser CORS restrictions) — checks for typosquatting, IP-literal and obfuscated-IP hosts, punycode/homograph encoding, credential-harvesting keywords, dangerous file extensions, open-redirect parameters, excessive subdomains, and known shortener/TLD abuse patterns.
How "AI" is used: the score is produced by a deterministic, weighted multi-model heuristic engine (four categories shown above), and the analysis text is template-generated from the triggered signals. It is a teaching / triage tool, not a live ML classifier or a substitute for a maintained threat-intel feed.
